# Codestra Repository Agent Start Index

This page is the portfolio-wide starting index for Claude Code, GitHub Copilot coding agent, Codex, and other engineering agents.

## Universal start

- [Agent Quick Start](https://github.com/ingtrader21-spec/codestra/blob/main/docs/AGENT-QUICKSTART.md)
- [Detailed Continuation Protocol](https://github.com/ingtrader21-spec/codestra/blob/main/docs/AGENT-CONTINUATION-PROTOCOL.md)

Every agent should receive:
1. repository URL;
2. active Linear issue URL;
3. role: Builder, Reviewer, or Verifier;
4. the Quick Start link above.

## Mission consistency

The portfolio mission is to deliver **governed, production-ready Codestra platform and product components that can be safely continued by different agents and machines without losing context or bypassing quality/security controls**.

The repository-specific goal is resolved from:
**Linear → Notion → `.codestra-mission` → repository architecture/docs → portfolio mission**.

For the current core production program:
- Middleware V3 — PAS-234
- Caddy — PAS-235
- Kong — PAS-236
- Keycloak — PAS-237
- Odoo 19 — PAS-238
- OpenBao — PAS-239
- Parent production-readiness program — PAS-247
- Final production-ready certificate — PAS-251

Product/application repositories keep their own product mission while integrating with shared platform contracts where applicable.

## Empty repository rule

Repositories with no default-branch history cannot safely carry repo-local agent files yet. Use the central Quick Start and Protocol until the repository's actual source history is published. Do not seed an empty remote with an unrelated documentation commit if preserved local history exists.

Continue this existing Codestra project.

Repository:
<REPOSITORY_URL>

<LINEAR_ISSUE_URL>

Role:
<Builder | Reviewer | Verifier>

Read the repository-local agent and mission files first.
Resolve the actual repository goal from Linear and Notion.
Preserve all existing work.
If Builder, verify exclusive issue ownership and use a dedicated worktree.
Continue the current mission through its next evidence-based gate.
Update GitHub + Linear + Notion + the checkpoint before handoff.
Do not cross the live-production approval boundary.
